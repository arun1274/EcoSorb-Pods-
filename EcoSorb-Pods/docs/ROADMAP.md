# Implementation and validation roadmap

- [x] Sample JSON spill fixture (fictional) and documented input schema
- [x] Basic rectangular zone planner, coverage paths and cartridge-equivalent estimates
- [x] Simulated battery/cartridge transitions and unit tests
- [ ] Sentinel-1/GEE connector, supervised oil-vs-lookalike validation and ground-truth samples
- [ ] Arbitrary geodesic polygon handling, currents-aware routing and collision prevention
- [ ] Controlled absorption-capacity and water-uptake lab tests for kapok cartridges
- [ ] ESP32 firmware, GPS hardware, ESC control and sensor calibration
- [ ] LoRa gateway, telemetry reliability and security tests
- [ ] Safety case: geofencing, remote stop, communications loss, leak monitoring
- [ ] Water tank, sheltered-water and permitted field evaluations

**Metrics proposed for future trials:** precision/recall of validated spill classification; oil mass recovered; oil/water selectivity; coverage fraction; navigation error; battery endurance; pod availability; LoRa packet delivery rate. No empirical values are claimed.
